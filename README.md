# CHA&S - Craftable Horse Armour & Saddle

Makes horse armour and saddles craftable. Fabric (needs Fabric API), Forge and NeoForge.

## Recipes

These are the only recipes the mod adds. Older screenshots on the mod pages may show earlier versions.

| Result | Top row | Middle row | Bottom row |
|---|---|---|---|
| Saddle | Leather, Leather, Leather | String, -, String | Iron Ingot, -, Iron Ingot |
| Iron Horse Armour | -, -, Iron Helmet | Iron Ingot, White Wool, Iron Ingot | Iron Leggings, -, Iron Leggings |
| Golden Horse Armour | -, -, Golden Helmet | Gold Ingot, White Wool, Gold Ingot | Golden Leggings, -, Golden Leggings |
| Diamond Horse Armour | -, -, Diamond Helmet | Diamond, White Wool, Diamond | Diamond Leggings, -, Diamond Leggings |

Leather horse armour uses the vanilla recipe, so the mod does not add its own.

Every recipe is a plain data file under `data/chas/recipe/`, so a data pack can change or remove any of them.
