# Changelog

## 3.1.0 for Minecraft 26.3 (Fabric, NeoForge)

- Updated to Minecraft 26.3. Needs Java 25, Fabric Loader 0.20.1+ with Fabric API, or NeoForge 26.3
- Forge builds are discontinued; use the NeoForge build
- Recipes rewritten for the current data format, so they load again
- Only one saddle recipe: the CHA&S saddle (leather, string, iron) replaces the vanilla one added in recent Minecraft versions (#15)
- The leather horse armour recipe now also applies on NeoForge, where NeoForge's own copy used to win
- Removed a duplicate leather horse armour recipe on Fabric
- Iron, gold and diamond in the recipes accept any item in the matching `c:` tag
- The mod icon now shows in the mods list

## 3.0.1 for Minecraft 1.21 and 1.21.1

- The Fabric build can be installed on Minecraft 1.21.1 (#16)
