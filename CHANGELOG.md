# Changelog

## 3.0.2 for Minecraft 1.21 and 1.21.1

- Recipes load again: 3.0.0 and 3.0.1 used the pre-1.21 data folder, so none of the mod's recipes existed in game
- Leather horse armour uses the vanilla recipe; the mod no longer replaces it
- NeoForge recipes use the `c:` tags, so modded iron, gold and diamonds work again
- Forge and NeoForge builds no longer install on Minecraft 1.21.2 or newer, which they do not support
- The mod icon now shows in the mods list
- The README lists the current recipes; the old mod page banner is outdated (#15)

## 3.0.1 for Minecraft 1.21 and 1.21.1

- The Fabric build can be installed on Minecraft 1.21.1 (#16)
